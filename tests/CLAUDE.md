# tests
Rodar (na pasta RPA): `.\.venv\Scripts\python.exe -m unittest discover -s tests` (65 testes, ~35-75 s; sem Citrix nem SRP). `test_atualizacao.py` — versoes, API de releases simulada, download com SHA-256 (zip local via file://). O GitHub Actions roda a mesma suite a cada push (`.github/workflows/testes.yml`).
- `simulador.py` — SRP falso (`SRP`: campos travados por linha, `recusar` = Tab que nao avanca, como um aviso) e `ambiente()`, que troca teclado/tela/OCR do `core` por falsos e manda logs e `aprendizado.json` para uma pasta temporaria.
- `test_fluxo.py` — campos travados (4 combinacoes, linhas mistas, sem cabecalho), pausa por aviso (corrige+Tab, esquece o Tab, linha feita a mao, sem Continuar), leitura do aviso e conta aprendida, pausa por quantidade divergente.
- `test_ocr.py` — OCR em celulas reais (`imagens/`, so numeros) e numa bateria sintetica; leitura de aviso desenhado. Pulados se nao houver `vendor/tesseract`.
- `test_planilha_tela.py` — leitura/validacao da planilha, itens repetidos, bloco ciano, coluna do foco, regra da Conta pelo vao, andamento salvo (`progresso.json`), limpeza de logs antigos.
Ao mudar o `core`, rode a suite antes de recompilar. Nao use imagens com dados da empresa alem de numeros soltos.
- `test_snac0236.py` — SNAC0236: formatos da planilha (chave como texto, filial em 2 partes, data, ponto decimal), agrupamento por chave e erros; rotulos pelo OCR; fluxo com SRP simulado (`SRP0236`: Enter avanca, clique no Integrar grava a nota): 2 notas, Enter a mais ate o campo certo, campo nao alcancado, campo sem cor (lista), Valor Unit amarelo (entra pela rolagem; Enter parado = pausa), Rateio (grade de tributos simulada: sem/com imposto, 2 itens, campo que nao para = pausa; Tributos OK fecha), aviso do frete CIF depois do 2o Integrar, janelas ja durante os 7 Enter (sem Enter na janela do Frete LTCC), cursor fora da Chave, foco partido unido, aviso no meio (pausa e usuario termina), sem Continuar, sem rotulos.
