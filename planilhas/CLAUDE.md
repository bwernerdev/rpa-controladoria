# planilhas
Planilhas Excel do dia (`.xlsx`/`.xlsm`), cabecalho na linha 1: `Item`, `C/Custo`, `Conta`, `Quantidade`. Partir de `BASE PADRAO.xlsx` (so o cabecalho; Item, C/Custo e Conta formatados como texto para manter zeros a esquerda). SNAC0236: partir de `BASE PADRAO SNAC0236.xlsx` (aba Notas ativa = so o cabecalho de `snac0236.TITULOS`, 1000 linhas ja formatadas: CHAVE NF/FILIAL/ITEM/OPER texto, data, casas decimais, FRETE com lista CIF/FOB; aba Instrucoes = regras e exemplo FICTICIO). Gerada por `scripts\gerar_base_0236.py` (mudou coluna ou regra: rodar de novo). As planilhas de trabalho nao vao ao git; so este arquivo e as duas bases padrao (as duas vao no zip do release e o `instalar.ps1` copia `BASE PADRAO*.xlsx`). Se a planilha estiver aberta no Excel, o robo le sem problema, mas ela nao pode ser movida/apagada.
